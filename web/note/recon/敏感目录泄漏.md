# 敏感备份文件
## gedit 备份文件
gedit 会生成后缀为 ~ 的备份文件。  

## vim 备份文件
因为网络问题或意外退出，vim 会生成：`.文件名.swp` 的文件用于备份缓冲区中内容。  
可以用 `vim -r` 恢复文件内容。
