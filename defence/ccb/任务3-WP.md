# 任务 3：植入的隐藏路由

## 题目要求

给出攻击者植入系统中的功能路由完整路径。

提交格式：`flag{<完整路由路径>}`

## 分析过程

先查看该路由在攻击者扫描阶段的响应：

```bash
grep -n "/api/v2/health" /var/log/nginx/access.log
```

攻击者 `203.0.113.7` 在 03:38 至 03:41 多次访问该路径，但均返回 `404`：

```text
203.0.113.7 - - [12/Aug/2026:03:41:55 +0800]
"GET /api/v2/health HTTP/1.1" 404 ...
```

在后续利用和后台操作之后，同一路径由 `198.51.100.23` 访问并返回 `200`：

```text
198.51.100.23 - - [12/Aug/2026:04:17:57 +0800]
"POST /api/v2/health HTTP/1.1" 200 96 "-" "Java/1.8.0_402" 0.021
```

这说明 `/api/v2/health` 在植入后成为可用的隐藏功能路由。

## 结论

```text
flag{/api/v2/health}
```
